## Resumen Ejecutivo
Estrategias de aseguramiento de calidad (QA) mediante pruebas unitarias e integración continua.

---

## Contenido Técnico Oficial
1. Marco PHPUnit
Permite ejecutar miles de pruebas unitarias sobre una base de datos aislada temporal para verificar que las funciones del core y plugins se comportan según especificación.
2. Pruebas de Comportamiento Behat
Pruebas funcionales y E2E basadas en lenguaje Gherkin que controlan navegadores reales para validar flujos de usuario (matriculación, entrega de tareas, calificaciones).
