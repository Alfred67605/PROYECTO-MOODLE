Resumen Ejecutivo: Procedimientos de respaldo consistente de los tres componentes esenciales de Moodle.

1. Los Tres Componentes Esenciales

  1. Código Fuente (Moodle Core): Directorio de scripts PHP. Respaldado vía Git o paquete tar.gz.
  2. Base de Datos (PostgreSQL): Dumps transaccionales consistentes generados con pg_dump.
  3. Directorio de Datos (moodledata): Almacén de archivos físicos (filedir), cachés y certificados.

2. Respaldo Automatizado de Cursos (.mbz)

Moodle genera paquetes de archivo de curso comprimidos en formato MBZ que contienen la estructura curricular, banco de preguntas, recursos y opcionalmente los datos de los usuarios.
