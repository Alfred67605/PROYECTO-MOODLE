Resumen Ejecutivo: Compendio de cambios, nuevas características, problemas resueltos y soporte de versiones en la rama 5.3.

1. Aspectos Destacados de Moodle 5.3

  • Soporte y optimización nativa para PostgreSQL 17 y 18.
  • Compatibilidad formal completa con PHP 8.4.
  • Mejoras sustanciales en la interfaz de usuario en el tema Boost.
  • Refuerzo de las comprobaciones internas de seguridad y privacidad.

2. Requisitos del Sistema para Moodle 5.3

  • PHP: versión mínima 8.3.0.
  • PostgreSQL: versión mínima 17.0.
  • MariaDB: versión mínima 11.4.0.
  • MySQL: versión mínima 8.4.0.
